# SEO

SEO is a core architectural requirement. The goal is strong technical SEO plus original content, not keyword stuffing or spammy behavior.

## Canonical Identity

- Canonical origin: `https://caroline-marques.com`
- Public identity: Caroline Marques
- Identity metadata should come from central site configuration.

## Required Capabilities

- canonical URLs
- unique page titles
- useful meta descriptions
- OpenGraph metadata
- Twitter/social metadata where sensible
- XML sitemap
- RSS
- `robots.txt`
- semantic heading hierarchy
- meaningful internal links
- image alt text
- good performance and Core Web Vitals
- static HTML by default
- structured data
- consistent public identity

## Structured Data Plan

- `Person` for Caroline Marques as the site owner.
- `ProfilePage` for profile-oriented pages.
- `Article` for long-form articles.
- `BlogPosting` where the content is clearly blog-style writing.
- `WebSite` for the site as a canonical public hub.

Structured data should be generated from typed configuration and content metadata where practical. Do not duplicate identity fields by hand across pages.
